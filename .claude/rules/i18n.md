# Translations

- The English source string is the key; there is no `en.json`.
- `de.json` and `nl.json` are required: a missing or stale German or Dutch
  entry fails `check-i18n.mjs`. `es.json` is reported, not enforced, but every
  new or changed string still gets German, Spanish **and** Dutch in the same
  change (owner, 2026-10-29: "include Dutch in your translation related actions
  from now on"). Dutch became required when it arrived complete (#324).
- Dutch addresses the user as *je/jij*, like the German *du*; buttons are
  infinitives ("Opslaan"). The terms used are in the glossary in
  `docs/decisions.md` (2026-10-30, Dutch).
- Do not reword an English string to fix a translation; that orphans the key
  in every catalogue. Fix the catalogue.
- `node web/scripts/translate.mjs` exists for bulk work; review its output.
- Server errors are translated by code in `serverErrors.ts`, not by their
  English text.
