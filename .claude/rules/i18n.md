# Translations

- The English source string is the key; there is no `en.json`.
- `de.json` is required: a missing or stale German entry fails
  `check-i18n.mjs`. `es.json` is reported, not enforced — fill it when you can.
- **Dutch too** (owner, 2026-10-30: "include Dutch from now on"). `nl.json`
  arrives with #324, in its own pull request after the rename. From then on
  every new or changed string gets German, Spanish **and** Dutch in the same
  change. Dutch is reported like Spanish until the file is complete, then
  required like German (`check-i18n.mjs`).
- Do not reword an English string to fix a translation; that orphans the key
  in every catalogue. Fix the catalogue.
- `node web/scripts/translate.mjs` exists for bulk work; review its output.
- Server errors are translated by code in `serverErrors.ts`, not by their
  English text.
